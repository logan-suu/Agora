## 🔄 重试任务

### 第一步：定位目标任务
1. 读取 `docs/task-status.json`。
2. 如果用户指定了任务 ID，则锁定该任务。
3. 如果未指定，则查找第一个 `status: "in_progress"` 的任务（可能是中断的）。
4. 如果找不到进行中的任务：
   - 输出："✅ 当前没有中断的任务。"
   - 列出当前所有 `ready` 任务状态。
   - 询问用户是否执行 `/next-task-agora`。

### 第二步：检查状态
1. 输出该任务的 ID、标题、所属阶段和当前状态。
2. 检查任务 `notes` 中是否有中断原因或上次进展记录。
3. 检查工作区：`git status --porcelain` 是否有半成品变更；如有，先分析这些变更与任务的关系（继续用 / 丢弃 / 重做）。
4. **等待用户确认**重试。

### 第三步：重新执行任务
1. 用户确认后，读取任务的 `documents_required` 文档与相关 `standing_decisions` 条目。
2. 检查是否有未完成的代码/测试（对照计划中已声明的文件清单）。
3. 继续执行 EPCC-V 流程：
   - 从上次中断点恢复（不重做已完成的部分）
   - 写测试 → `pnpm test` → 写实现 → `pnpm test`
4. 如果执行成功：运行 `pnpm typecheck && pnpm lint`，然后提示用户执行 `/commit-agora` 提交推送。
5. 如果仍然失败：
   - 分析错误日志
   - 输出诊断建议（引用相关文档原文）
   - 连续 3 次修复失败：停止编辑，恢复到最近可用状态，输出失败上下文并询问用户是否升级处理

### 第四步：交付
1. 任务完成后提示用户执行 `/commit-agora` 提交推送（推送成功后标 `done`）。
